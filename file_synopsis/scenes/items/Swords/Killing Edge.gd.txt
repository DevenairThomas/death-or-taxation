SYNOPSIS: scenes/items/Swords/Killing Edge.gd

1. CLASS
No class_name; extends "res://scenes/items/Item.gd" (Item / Node2D). Concrete weapon
script for Killing Edge.tscn.

2. WHAT IT DOES
A high-crit assassin sword. _ready() sets uses/max_uses 30, might 9, weight 7, hit 70,
crit 30 (its defining stat), range 1-1, worth 1300, strong_against AXE, icon
killing_edge_icon.png, weapon_string_name "sword". Registered in Item_Dict.all_items and
seeded into the convoy demo (convoy.gd adds one). Its whole identity is the RNG crit
multiplier — precisely the mechanic DoT bans.

3. FUNCTIONS
- _ready(): assigns stats on spawn.
- draw_attack_sound() / put_away_attack_sound(): play the standard draw/put-away SFX from
  BattlefieldInfo.weapon_sounds.
- special_ability(unit_holding_this_item, unit_that_is_being_attacked): returns 1 (params
  named but unused). Damage-multiplier hook; the crit itself is handled elsewhere via the
  `crit` stat + RNG, not here.

4. POSSIBLE IMPROVEMENT
- Data belongs in a Resource/data table, not _ready().
- `crit` as a probabilistic stat couples this item to an RNG combat path; if kept for the
  FE reference, the crit resolution should be isolated and testable.

5. RELATION TO DEATH OR TAXATION
FULLY SCRAPPED — and a direct spec violation if ported. DoT combat is 100% deterministic:
NO crit, hit, dodge, or luck values anywhere. The Killing Edge's reason to exist (crit 30)
is explicitly cut. Nothing about this item carries over; it is the clearest example in the
folder of a mechanic DoT forbids.
