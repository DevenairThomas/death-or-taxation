FILE: scenes/units/Enemy_Units/Dark Mage Enemy.gd

1. CLASS
No class_name. extends Battlefield_Unit. Concrete enemy unit definition (dark/tome caster).

2. WHAT IT DOES
Spawn config for an enemy dark mage: base setup, enemy flag, idle anim, red-soldier portrait/mugshot, a Flux dark tome loadout, and the dark-mage combat scene.

3. FUNCTIONS
- _ready(): super._ready(); $Animation.current_animation="Idle"; UnitMovementStats.is_ally=false; unit_portrait_path and unit_mugshot = red soldier portrait; appends Item.WEAPON_TYPE.DARK to usable_weapons; adds preloaded Flux tome; combat_node = preload("Dark Mage Enemy Combat.tscn"). Touches Battlefield_Unit, $Animation, UnitInventory, Item enum.

4. POSSIBLE IMPROVEMENT
- Same content-as-code issue; move to data.
- Uses the generic red-soldier portrait for a mage (placeholder mismatch).
- Magic damage in FE keys off UnitStats.magic vs. defender res — none of that is set here, so it leans on placeholder stats.
