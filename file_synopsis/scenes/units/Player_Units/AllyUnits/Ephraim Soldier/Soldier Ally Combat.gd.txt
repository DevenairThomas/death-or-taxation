FILE: scenes/units/Player_Units/AllyUnits/Ephraim Soldier/Soldier Ally Combat.gd

1. CLASS
No class_name. `extends "res://scenes/units/Unit_Scripts/Combat Unit.gd"` (Combat_Unit, Node2D).
Combat-animation controller for the generic soldier's battle scene.

2. WHAT IT DOES
Overrides only the miss-SFX/dodge hook for the soldier's battle animation. Invoked by the combat
scene's AnimationPlayer method tracks. Does not override death handling (uses base Combat_Unit).

3. FUNCTIONS
- signal play_enemy_dodge_anim: opponent dodge cue on miss.
- play_miss_sound(): random "Attack Miss 1..2" from BattlefieldInfo.battle_sounds; emits
  play_enemy_dodge_anim.

4. POSSIBLE IMPROVEMENT
- Verbatim duplicate of base Combat_Unit.play_miss_sound(); the subclass is unnecessary — attach
  Combat Unit.gd directly.
- Same randf_range->int off-by-one; use randi_range.

5. RELATION TO DEATH OR TAXATION
SCRAP. No per-unit combat-animation scenes or miss mechanic in DoT. Generic troops are SQUADS/SINGLES
whose combat is deterministic sim math surfaced via signals to a shared view; no bespoke combat
subclass.
