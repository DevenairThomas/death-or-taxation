SYNOPSIS: scenes/battlefield/chapter_5.gd

FILENAME NOTE: Named chapter_5, but the CONTENT is the Chapter 4 mission ("4\nThe Great Fortress Line", enemy commander "Byzantine", objective Victory_Checker.SEIZE, event L4_Event_Part10, +1500 money, prep screen). Chapter file names are offset from their content numbers. This is the only in-scope chapter using the SEIZE objective.

1. CLASS
   extends Node2D (no class_name). Per-chapter/mission setup for Chapter 4, using a SEIZE (capture-the-HQ-tile) win condition and the preparation phase.

2. WHAT IT DOES
   Configures the Chapter 4 mission (camera/cursor at origin, music, SEIZE victory, enemy commander, single L4 event), adds 1500 money, reparents the party, and runs the prep phase. Provides next_level(), start_battle(), preperation_mode(). Structurally near-identical to chapter_4.gd but with victory_condition_state = Victory_Checker.SEIZE and no explicit save-guard around adding money/prep.

3. FUNCTIONS
   _ready(): registers as level_container; sets camera (0,0) and cursor (0,0); sets music; victory_system.clear() -> victory_condition_state = Victory_Checker.SEIZE; caches enemy_commander["Byzantine"]; clears event_system, adds L4_Event_Part10; if not loading, money += 1500; reparents player party into the level; calls preperation_mode(); makes allies visible; clears container modulate; attempts to free a stale chapter node (note: the guard uses a malformed path "root/Level/Chapter 4" missing the leading slash, so the free likely never fires).
   next_level(): reparents surviving allies back to the y-sort. (Unlike the other chapters, this stub does NOT stop music, fade, or trigger a SceneTransition — it appears incomplete, consistent with this being the last currently-authored playable chapter / where the reference project stops.)
   start_battle(): start events queue + play music.
   preperation_mode(): same as chapter_4 — opens preparation_screen, shows cursor + HUD, sets turn_manager.turn = WAIT, sets all ally units to MOVE for placement.

4. POSSIBLE IMPROVEMENT

   - SEIZE win condition here has no visible tile/HQ wiring in this script — it relies entirely on Victory_Checker's internals.
