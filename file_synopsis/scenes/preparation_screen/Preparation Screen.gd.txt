FILE: scenes/preparation_screen/Preparation Screen.gd

1. CLASS
- No class_name. extends CanvasLayer.
- The pre-battle Preparation screen. Registers itself as BattlefieldInfo.preparation_screen (singleton-like accessor). Instanced within the battlefield context; owns a menu (Select/Inventory/Map/Market/Save), a hand selector, a unit-select ItemList, a Shop, and prep-theme music tracks.

2. WHAT IT DOES
- The FE deployment/prep hub shown before a chapter: choose which allies deploy, manage inventory, preview the map and set start positions, visit the marketplace, and save. It seeds ally units onto "swap point" tiles, heals/resets them, plays prep music, and on "start_battle" transitions the cursor/camera and hands off to the level container to begin combat.

3. FUNCTIONS
- _ready(): Disables input, registers BattlefieldInfo.preparation_screen = self.
- start(chapter_text, victory_text, path_to_next_level, prep_song): Removes lingering Intro Screen; clears ally currentTile refs then assigns each ally (except Eirika) to a free swap_point tile; heals all allies to max and resets action status/greyscale; plays prep music; sets chapter title + victory-condition text; resets hand + menu option; resets turn_manager turn numbers to 1; fades in and enables input. (Note: has a stray backslash after the signature line.)
- _input(event): Up/Down move the menu option + hand and update side text; ui_accept -> process_selection; "start_battle" action -> start_battle().
- set_side_text(): Sets the side panel help text per current option.
- process_selection(): "Select" -> opens Unit Select ItemList (multi-select) and temp-disables menu; "Inventory" -> sets text; "Map" -> hides prep, enables main camera + battlefield HUD, turns on blue swap tiles, sets cursor to PREP mode; "Market" -> opens Shop, hides prep UI, stops music; "Save" -> BattlefieldInfo.save_load_system.save_game(), awaits saving_complete, shows "Game Saved!".
- play_song(song_name)/stop_music(): Prep theme A/B control.
- start_battle(): turn_off(); disables cursor UI; moves main camera to Eirika, clamps, moves cursor to Eirika and fires cursorMoved; plays "Start Battle" anim; stops music; calls BattlefieldInfo.level_container.start_battle().
- turn_on/turn_on_fade/turn_on_without_anim/temp_disable/turn_off: Visibility + input-enable helpers for the menu.
- Interactions: BattlefieldInfo (ally_units, swap_points, Eirika, turn_manager, main_game_camera, cursor, battlefield_ui, save_load_system, level_container), Unit_Action_Status, Cursor states, ItemList.SELECT_MULTI.
